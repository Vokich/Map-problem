Название программы: "Карта городских проблем" 
Аннотация:
  Веб-приложение для опубликования, визуализации и управления городскими проблемами. 
  Позволяет пользователям помечать на интерактивной карте проблемы инфраструктуры, 
  безопасности, благоустройства и др., отслеживать их статус. 
  Реализована система регистрации пользователей, загрузки фото, 
  интерактивная карта с маркерами, фильтрация по типам и статусам проблем.
  Назначение: улучшение взаимодействия жителей с городскими службами.
  Область использования: муниципальное управление, гражданские инициативы.
  Функциональные возможности:
    - Добавление проблем с координатами и фото
    - Интерактивная карта с кластерами маркеров
    - Система статусов (новая/в процессе/решена)
    - Личный кабинет пользователя
    - Экспорт данных о проблемах

Тип реализующей ЭВМ: веб-сервер с доступом из браузера
Вид и версия СУБД: SQLite 3 
Вид и версия ОС: Кроссплатформенное (Linux/Windows/macOS), требуется ОС с поддержкой Python 3.8+
Объём программы в машиночитаемой форме: ~ 2 МБ (исходный код + статика)
Язык программирования: Python 3.8+, HTML, CSS, JavaScript
Фреймворк: Django 5.2.7
Библиотеки: Leaflet.js, OpenStreetMap API
